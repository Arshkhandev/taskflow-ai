# 🚀 TaskFlow AI Backend

A production-ready MERN backend for an AI-powered task management application.

TaskFlow AI helps users organize projects into boards and tasks while leveraging Google's Gemini AI to generate tasks, break down complex work, suggest priorities, estimate due dates, and improve task descriptions.

---

# ✨ Features

## Authentication

- User Registration
- User Login
- JWT Authentication
- Protected Routes
- Password Hashing (bcrypt)

---

## Boards

- Create Board
- Get Boards
- Get Board By ID
- Update Board
- Archive Board
- Delete Board

---

## Tasks

- Create Task
- Get Board Tasks
- Get Task By ID
- Update Task
- Archive Task
- Delete Task

---

## AI Features

- Generate Tasks from Goal
- Generate & Create Tasks
- Break Down Task
- Suggest Priority
- Suggest Due Date
- Improve Task Description
